验证与限制

本轮新增桥接、MCP 与运行时三组隔离回归，并纳入 npm run test:audit。 离线套件不枚举本机 DSH 安装包，避免宿主机包规模影响测试时限；工具权限和预设的离线断言继续执行， 升级 DSH 后仍应单独运行 npm run scan:tool-names 对账实际工具名。 凭据、服务端、令牌与 ACL 都由测试夹具模拟；未对用户机器执行真实 ACL 收紧、DSH 升降级或 QQ 发送。 完整离线套件结果为 Audit suite: 54/54 scripts passed.；桥接跟进 16 组、MCP 跟进 14 组、 运行时跟进 11 组全部通过。129 个 JS/MJS/CJS 文件语法、9 个 JSON 解析和默认规则隐私扫描通过。 远端 CI 以 fix-a/dev 对应提交的运行结果为准。
