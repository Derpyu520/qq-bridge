2026-10-31 仓库体检与修复

审计基线为 dev 分支的 c893c7b。范围覆盖桥接与控制台、MCP 工具、网络请求、 预设权限、学习资料、语音路径、运行时状态、依赖和 CI；采用代码审查、隔离夹具和回归测试。 没有操作真实 QQ/DSH 会话，也没有修改运行配置、聊天记录或仓库历史。

已修复的问题

P1 表示可能泄露私有资料或违反用户撤权意图，P2 表示安全边界或健壮性缺口； 这是本次代码审计的优先级判断，不是 CVSS 评分。

优先级问题与影响修复
P1黑话创建丢弃 scope，同名词跨会话合并；查询、提示词和提交可能返回别群解释创建保留归属，按内容和 scope 更新，所有模型读取按 scope 过滤
P1黑话研究共享学习历史，且按全库同名词回写，可能混合证据和覆盖其他条目按 scope 分批并隔离学习会话，只向本批目标 ID 和 scope 回写
P1贴纸 API、搜索及部分更新可能泄露或搬运其他会话的 AI 认知返回与搜索前净化私有字段，切换归属清空旧备注、标签、用途和语境
P1排队或异步准备中的 AI 动作可能在暂停、关闭、静默或权限变化后继续发送提前捕获权限，在实际发送前重查；覆盖文本、语音、表情与拍一拍
P1搜索兼容端点回显的 API key 可能随错误或搜索结果进入模型错误只返回稳定状态，结果字段在截断前精确脱敏，兼容短 key
P2SSRF 过滤遗漏特殊云平台地址补充 Azure WireServer 地址及嵌入式 IPv6、DNS、重定向回归
P2MCP 网页抓取未使用已有端口限制与媒体抓取统一限制 80/443/8080/8443
P2DSH 自动探测可为远端候选铸造本机 Cookie，RPC 默认跟随重定向自动探测仅限回环，拒绝 URL 内嵌凭据；探测和 RPC 均不跟随重定向
P2语音库新文件不存在时跳过真实父目录校验校验最近已存在父目录，拒绝库外 junction 和失效链接
P2预设生成物检查把 Windows 检出的 CRLF 当成源与产物漂移，干净工作树也可能失败比较前统一文件换行，保留真实 YAML 字段和内容差异检查

新增四组离线回归，同时把已有预设装配、工具守卫、媒体、贴纸、转发、等待和路由测试纳入 npm run test:audit。CI 增加依赖检查，阻止已知高危和严重漏洞。 贴纸、转发和等待测试的默认值检查改读示例配置，干净克隆无需提供本机配置； 转发实机检查只有显式 QQ_BRIDGE_TEST_LIVE=1 时才启用，离线套件强制关闭该开关。

升级后的资料复核

旧版本已经错误保存为 global 的 AI 黑话仍按全局语义可见。过去同名词合并后，解释和证据也可能已混合。 管理员应在控制台复核旧 AI 条目，删除或重新指定归属。本次不自动重写现有资料：缺失的归属无法可靠恢复， 而有意设为全局的条目也应继续共享。新数据已在创建、研究、读取和更新全链路隔离。

历史隐私扫描还报告 15 处旧提交中的本机路径。当前工作树未命中；这些历史命中不因普通修复提交消失。 本次未改写公开历史。需要清理时应另行制定与已有克隆、分支和 fork 协调的方案。

架构与剩余风险

src/bridge.js 约 1.2 万行，同时承担 HTTP 路由、鉴权、调度、外部协议和持久化，安全规则容易在旁路遗漏。 此次统一复用了发送守卫和按归属净化函数；后续适合分阶段提取服务层，先保留现有行为回归，再拆控制台路由和资料存储。

src/core/session-router.mjs 有独立测试，但尚未接入实际桥接链路，与主文件里的策略实现并存。 其测试通过不能证明生产路由使用了这套策略，后续应明确集成路径或删除未使用抽象。

敏感内容检测仍是启发式规则；本机状态中的秘密仍依赖 ACL 保护；网络、DSH、SnowLuma 的实际端到端行为 需要在维护窗口另做验证。本次离线审计不构成没有未知漏洞的保证。相关边界详见 安全基线。
