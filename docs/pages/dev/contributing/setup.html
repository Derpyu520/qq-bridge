开发环境

先把两件事说在前面：这个项目只在 Windows 上跑，维护者通常会直接把改动提交到 dev。 后者会影响你怎么提 PR，所以第 4 节请读完。

1. 环境

需要版本说明
Windows10 / 11大量依赖 Windows 的 ACL、控制台编码与进程行为；测试矩阵只覆盖 Windows
macOSApple Silicon有实测运行记录，不在测试矩阵内；没有守护与停实例脚本、DSH 端口不自动发现，见 macOS 安装
Linux—未验证
Node.js>= 22.13见 package.json 的 engines
npm随 Node仓库带 package-lock.json，请用它锁定版本

2. 本地跑起来

git clone https://github.com/Derpyu520/qq-bridge.git
cd qq-bridge
npm install
npm run test:audit

⚠️ 不要用 npm ci --ignore-scripts。postinstall 会跑 scripts/patch-snowluma-sdk.mjs， 给 @snowluma/sdk 的相对导入补 .js 扩展名（这两个上游包自己的 ESM 打包有问题）。 跳过它，test-snowluma-upstream-health.mjs 会稳定失败——那是预期行为，不是你的改动坏了。
