DSH 升级清单

6. 下次 DSH 升级的增量清单

沿用 DSH_020_ADAPTATION.md §10，本轮补充三条：

  1. verify:adaptation 必须有"真跑一回合"：静态断言看不出提示词变量被删。 本轮之前它只查"preset 里有没有 {{cwd}}"，而 {{cwd}} 恰恰是坏的那个。
  2. 先看 state/tool-restrict.log 的 known global tools——它是"全局层到底有什么"的第一手证据， 新增名字基本等于 1 个必须补的守卫条目。别只看 restrict ok= 的分子：大部分名字是 scoped 工具， restrict 对它们本来就抛错，要看的是失败样例里有没有全局工具。
  3. 升级后立刻跑一次 node scripts/probe-tools.mjs qq-chat-v2：它同时覆盖 persona 装配、工具面、MCP 调用三条链路，是全仓库最便宜的一次端到端体检。
