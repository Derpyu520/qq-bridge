配置参考

2. 填写配置

编辑 config.json，至少核对这些字段：

字段填写内容
dsh.baseUrlDSH Web 地址，默认 http://127.0.0.1:3080；模型选择需与 DSH 中可用的配置一致
snowluma.wsUrl / httpUrlOneBot WebSocket / HTTP 地址，示例分别为 ws://127.0.0.1:3001 / http://127.0.0.1:3000，不要混用端口
snowluma.accessToken / homeDir按实际配置填写令牌与 SnowLuma 安装目录；HTTP、WS 令牌不同时，需能从该目录发现各自令牌
ownerQQ你的管理员 QQ 号
allow.private / allow.groups允许接入的 QQ 号 / 群号；默认空白名单不响应任何会话

同机运行时，dsh.authToken 通常留空，由桥接使用本机 DSH 凭据完成鉴权。完整配置与连接排查见安装指南。

六、配置

价目表默认内置，开箱即用。需要覆盖时在 config.json 加 pricing：

{
  "pricing": {
    "peakMultiplier": 2,
    "holidays": ["2027-01-01", "2027-02-06"],
    "models": {
      "my-relay-model": {
        "label": "我的中转",
        "off": { "cacheHit": 0.5, "cacheMiss": 3, "output": 9 }
      }
    }
  }
}
  • 只写要改的字段即可，其余继承默认值。
  • 自定义模型未写 cacheWrite 时自动跟随 cacheMiss。
  • 未登记的模型按 fallbackModel（默认 deepseek-flash）估算，并在控制台标 estimated。
  • 改了价目表不需要重算历史：金额一律在读取时折算。
