# 角色扮演文件

在群里对 QQ agent 说：

```
进入角色扮演：<角色名>
```

agent 会读取本目录下 `<角色名>.md` 文件并按其中设定扮演；说 `退出角色扮演` 恢复正常人格。

## 文件格式

每个角色一个 Markdown 文件，文件名 = 角色名（不含扩展名，中英文均可）。示例：

```markdown
# 角色名（可自定义，如：傲娇助手）

- 性格：傲娇、嘴硬心软，被夸会不好意思
- 说话风格：简短、带哼声（"哼！"），偶尔用 emoji
- 背景设定：你是管理员的老朋友，说话可以随意一点
- 与群友的互动规则：对每一条 @ 你的消息都回应，但不主动插话
- 特殊能力：可以用 QQ 工具帮群友查天气、找资料（正常使用 mcp__snowluma__ 工具）
```

## 提示

- 角色名建议用简短中文（如 `傲娇助手`、`猫娘`、`吐槽役`）
- 想换性格直接改文件内容，群里重新 `进入角色扮演：<角色名>` 即可生效
- 角色设定里可以要求保留某些工具能力（发消息、查群），也可以限定"只聊天不干活"
