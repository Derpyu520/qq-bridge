# assets/ —— 头像候选

控制台的「QQ 资料」与工具的 `qq_list_assets` / `qq_view_asset` 会读这个目录，用于换机器人头像。

## 规则

- 只放**你自己有权使用**的图片：自己画的、AI 生成且条款允许的、明确授权的。
- 支持 `png` / `jpg` / `webp` / `gif`，单个文件建议 < 2 MB、正方形最佳（头像会被裁成圆形）。
- 文件名随意，但不要用真人姓名；控制台按文件名排序。
- 不要把别人的画师作品、群友照片、带个人信息（水印、证件、聊天截图）的图放进仓库。

## 本仓库只带一张示例

`deepseek娘.png` 是社区常见的 DeepSeek 鲸鱼娘形象示例，仅用于演示头像选择流程。
想用你自己的形象：把图片放进这个目录，`.gitignore` 默认忽略 `assets/*`，只放行这一张示例图和
本说明——你需要时在本地使用即可，不必提交。
